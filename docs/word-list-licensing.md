# 官方字表授權調查（2026-10-28）

結論先說：**目前沒有任何官方字表被放進專案**。下面是查到的狀況與下一步。字庫已支援擴充包（`src/data/packs/*.json`，每個包要填 `license`），所以只要授權確認，放進去不用改程式。

| 字表 | 查到的事實 | 狀態 |
|---|---|---|
| 教育部國中小基本字彙 1,200 字（含於 12 年國教課綱的 2,000 字參考字彙表，附錄 5） | 在國家教育研究院公布的《英語文課程綱要》PDF 裡。PDF 本身沒有寫授權條款。國教院網站頁尾有「政府網站資料開放宣告」連結，但我沒能讀到內容。政府資料開放授權條款第 1 版（已讀）允許商用、改作、再散布，只要求標示出處，並與 CC BY 4.0 相容。 | **很可能可用，但還沒證實**：要先確認這份字表確實適用該開放授權（國教院開放宣告、或 data.gov.tw 資料集頁面） |
| 大考中心高中英文參考詞彙表（約 6,000 字，2020 年更新；舊稱 7,000 字） | 只找到轉述它的頁面（LTTC 頁面只說明它是參考來源），沒有找到授權或使用條款。市面上有很多廠商整理版，版權屬於他們。 | **不放**，除非查到大考中心官方條款或取得同意 |
| 全民英檢（LTTC / GEPT）字表 | 頁面只有「© LTTC」，沒有再利用條款。 | **不放** |
| 雅思、托福、多益 | 沒有官方公布的標準字表；坊間字表都是整理版，有版權。學術字表（AWL 等）的授權條件我沒查到明確結論。 | **不放**，需逐一查 |

## 做法建議

1. 先處理教育部字表：讀國教院「政府網站資料開放宣告」，或到 data.gov.tw 看該資料集的授權欄；必要時寄信問國教院。確認後，只收**英文單字本身**，詞性和中文解釋由我們自己標，並在包內寫明出處與「政府資料開放授權條款第 1 版」，App 內加上出處標示。
2. 大考中心：寄信詢問可否用於免費的學習遊戲；沒回覆前不放。
3. 單字本身是事實資料，著作權保護很薄；風險主要在別人整理過的排序、解釋、詞性、例句。所以即使最後要放，也只拿單字本身。

（這是我讀公開網頁的整理，不是法律意見。）
